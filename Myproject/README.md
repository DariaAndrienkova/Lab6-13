# Трекер екскурсій та подорожей

Для кого: для себе, щоб вести облік відвіданих місць, музеїв та екскурсій
Запис: дата, назва, категорія, вартість, тривалість, коментар
Операції: додати, показати всі, знайти за критеріями, видалити
Звіти: сума витрат за місяць, сума витрат за категорією, найбільша витрата

## Запуск

python cli.py add 2025-05-31 "Пирогово" музей 200 4.0 "Чудова прогулянка на свіжому повітрі в кінці травня"
python cli.py list
python cli.py find музей
python cli.py report

## Формат даних

data.txt, один запис на рядок: дата; назва; категорія; вартість; тривалість; коментар
