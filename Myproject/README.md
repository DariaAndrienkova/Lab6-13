# Трекер екскурсій та подорожей

Програма для збереження інформації про відвідані місця,
екскурсії та подорожі.

## Можливості

- Додавання нових екскурсій.
- Перегляд усіх записів.
- Пошук за категорією.
- Підрахунок витрат за категоріями.
- Підрахунок витрат за місяцями.
- Визначення найдорожчої екскурсії.
- Збереження даних у SQLite.
- Вебінтерфейс для роботи із записами.

## Поля запису

- Дата
- Назва місця
- Категорія
- Вартість
- Тривалість
- Коментар

## Запуск консольної програми

Додати запис:

python cli.py add 2026-11-16 "Пирогово" музей 200 3 "Екскурсія"

Показати записи:

python cli.py list

Знайти за категорією:

python cli.py find музей

Показати звіт:

python cli.py report

## Запуск тестів

python tests.py

## Запуск вебсервісу

python app.py

Сервер буде доступний за адресою:

http://127.0.0.1:8000/items
